# 별우물 아래 (Starwell Below)

떨어진 별 조각을 쫓아 우물 아래 지하 세계로 내려간 흙인형 **모아**의 메트로배니아 웹 게임입니다.
이어진 큰 지도 하나를 돌아다니며 능력을 얻어 막힌 길을 열고, 보스를 쓰러뜨려 별 심장에 닿으면 엔딩입니다.

- 방 66개 · 지역 6곳(뿌리 마을터, 수정 동굴, 잠긴 물길, 불씨 대장간, 바람 첨탑, 별 심장)
- 능력 6개: 이끼 장갑(벽 타기), 바람 신(대시), 구름 씨앗(이단 점프), 물방울 숨(수영), 무쇠 발(내려찍기), 불씨 구슬(불탄)
- 보스 6마리, 별돌 7곳(저장·회복), 숨은 체력 조각 13개·탄 강화 9개, 지도 화면
- Canvas 2D, 그림·소리 모두 코드로 그림(외부 파일 없음), 키보드·터치·게임패드, 저장은 localStorage

## 실행

```sh
node scripts/serve.mjs        # http://localhost:8650/
```

빌드 도구가 없는 정적 웹앱입니다. `web/` 을 그대로 올리면 됩니다(`npm run build` 는 검사 후 `dist/` 로 복사).

## 조작

← → 이동 · Z/스페이스 점프 · X 쏘기(↑ 누르면 위로) · C/Shift 대시 · 공중에서 ↓ 내려찍기 · M 지도 · Esc 멈춤.
벽에 붙어 ↑ 로 오르고, 붙은 채 점프하면 벽 차기. 게임패드는 A 점프 · X 쏘기 · B 대시 · Y 지도.

## 구조

| 경로 | 내용 |
|---|---|
| `web/js/physics.js` | 물리·충돌(순수 함수). 게임과 검사기가 같이 씀 |
| `web/js/worldspec.js` | 손으로 짠 지도·연결(능력 문)·방 특징·보스 |
| `web/js/data/rooms.js` | `tools/build-world.mjs` 가 만든 방 타일(손으로 고치지 않음) |
| `tools/solver.mjs` | 도달 검사기: 진짜 물리로 동작 묶음을 흉내 내 방 안 도달·지도 전체 진행을 계산 |
| `web/js/main.js` | 장면·방 넘기기·전투·저장·지도 |

## 시험

```sh
npm test                      # 물리 단위 시험 + 세계 자료 + 능력 잠금 그래프(지도 전체 도달·순서·잠금·갇힘)
PLAYWRIGHT_MODULE=<playwright 경로>/index.mjs npm run test:e2e   # 헤드리스 스모크(없으면 건너뜀)
node tools/build-world.mjs    # worldspec.js 를 고친 뒤 방 다시 만들기
```

능력 잠금 검사는 방마다 "그 능력 없이 그 문을 못 지나는지", 지도 전체는 "능력을 설계한 순서대로만 얻고 66방·모든 물건·모든 보스에 닿는지",
그리고 "닿은 어느 자리에서든 그때 능력만으로 별돌 방에 돌아갈 수 있는지"를 봅니다.
